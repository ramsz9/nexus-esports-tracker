# Nexus Esports Tracker

Plataforma web para centralizar el registro del roster de jugadores y su
historial competitivo de un equipo de esports.

Universidad Tecnológica de Chihuahua
Ingeniería en Desarrollo y Gestión de Software
Desarrollo Web Integral · Unidad I · Grupo IDGS91N

## Estructura

    backend/    API REST con Spring Boot   (puerto 8080)
    frontend/   Interfaz con Angular       (puerto 4200)

## Requisitos

    Java 21 · Maven · Node.js 22 · Angular CLI · PostgreSQL 17

## Ejecución

Backend:

    cd backend
    .\mvnw.cmd spring-boot:run

Frontend:

    cd frontend
    ng serve
